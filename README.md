One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet remembers the last person who woke it up at that hour — and it was not a customer. The program writes the line to `/output/entry.txt`.

> The last person to wake me up at 3 AM wore a ski mask and carried a USB cable. Come back when the sun can vouch for you.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program validates the line (1–200 characters, a single line, not only white space) and writes it to `/output/entry.txt`.
